# 日式海报风格图谱（Style Grammar）

本文件是从 100+ 张日式海报参考图中提炼的可复用设计规律。生成海报时按此图谱选择风格原型、配色、字体、版式与纹样。

## 一、核心美学原则（贯穿所有风格）

1. **留白（間 / Ma）**：大量负空间是日式设计的灵魂。元素通常只占画面 30%–60%，宁少勿多。
2. **克制的配色**：一张海报通常 1 个主色 + 1 个强调色 + 米白/象牙白底色。极少使用 3 种以上高饱和色。
3. **纵排文字**：日文/中文标题常竖排，从右向左读；英文横排作点缀。竖排文字右对齐、字距宽松。
4. **手写与规整并存**：毛笔/手绘字体（书道感）与精确的几何网格、衬线西文形成对比。
5. **材质与肌理**：和纸纹理、印章、网点、线描、水彩晕染制造"手作感"，避免纯数字的冰冷。
6. **印章点缀**：红色朱印（落款、logo、日期）是标志性元素，常用方形/圆形，置于角落或文字旁。
7. **图文互补**：插画/摄影常与文字重叠、嵌入笔画或置于异形轮廓（云形、花瓣形）中。

## 二、五种风格原型（Style Archetypes）

生成时先判断用户主题适合哪一种，再套用对应配方。用户未指定时按主题默认：美食→和食/和菓子风；展览/活动→极简留白或前卫排版；文艺/诗句→手写诗意风；品牌/店铺→传统纹样风。

### 原型 A：极简留白（Minimal Ma）
- **代表图**：一组简洁的日式排版、清新的日式海报、简洁的日式海报设计、日式展陈海报
- **底色**：象牙白 / 米白 `#F6F3EC`、`#FAF7F0`
- **文字**：疏朗竖排短句（如「朝に起きる。」、「ilent」），小号横排英文日期/地点；字体用明朝体（细），字距极大
- **图形**：极简单线元素——一个圆、一条曲线、几根交叉短线、小圆点 scattered
- **布局**：主体偏一侧，大面积留白；细线框；信息集中在底部或角落
- **配色**：米白 + 炭黑 `#2B2B2B` + 一点暖橙/金 `#C8A45C`
- **要点**：**少即是多**，一个视觉焦点即可

### 原型 B：传统纹样 / 和风店招（Traditional Pattern）
- **代表图**：【视觉】日式海报小集（大いちフルーツ）、CDBC 手みやげ広場、视觉感爆棚-2、有格调的日式海报
- **底色**：米白 `#F3EDE0`、浅灰白
- **文字**：大号手写体日文店名/主题居中或偏右；周围环绕小号竖排信息；英文小字 brand mark
- **图形**：家纹式几何标志（三圆/梅花）、朱印印章、青海波/麻叶/市松纹样、折扇、樱花、茶壶、达摩等民俗小图标（扁平剪影）
- **布局**：中心主体 + 四周环绕式小元素；网格底纹；印章散布
- **配色**：朱红 `#C0392B` / `#D32F2F`、藏青 `#1F3A5F`、米白、炭黑
- **要点**：元素丰富但有序，靠纹样网格统一

### 原型 C：和食 / 和菓子美食（Washoku / Wagashi）
- **代表图**：日式美食海报 1/2/3、日式海报 137、创意卡通水墨日式美味食物海报、花时日式料理
- **底色**：柔粉 `#F5E6E4`、奶油 `#F7F0E6`、淡杏 `#FCE8D5`
- **文字**：竖排诗意短语（「ほろり、とろける。」）在最右；小号竖排说明文字；底部产品小图 + 品名
- **图形**：主体食物照片/插画置于异形轮廓（云形、花形、六边形、圆）中；樱花、折扇、筷子元素
- **布局**：主体居中或偏左的大异形区 + 右侧竖排文案 + 底部信息条
- **配色**：柔粉/奶油底 + 食物本色（抹茶绿 `#7A8B5A`、红豆 `#8B4A3A`）+ 少量朱红点缀
- **要点**：食物是绝对主角，文字退居诗意陪衬

### 原型 D：前卫排版 / 视觉冲击（Avant-garde Typography）
- **代表图**：视觉感绝对爆棚-1/2（漂着劇・日本語のレイアウト）、平面设计 Typography、花时新品特惠
- **底色**：纯白 `#FFFFFF` 或米白
- **文字**：巨大毛笔字/装饰字体作主体，常倾斜、拉伸、嵌入图形；小号说明文字沿边排列
- **图形**：手绘线描插画（森林/城市/动物）、几何色块、斜向线条、圆点、撕纸/网点肌理
- **布局**：文字与插画满版交织，视觉重心明确，信息沿边缘环绕
- **配色**：白/米白 + 黑 + 单一强调色（翠绿 `#4A7C59`、玫红 `#C2185B`、朱红）
- **要点**：视觉张力强，字体本身即图形

### 原型 E：手绘诗意 / 插画叙事（Hand-drawn Poetic）
- **代表图**：Keisuke Nagatomo、脑洞大开的日式刺绣海报、日式插画海报（蘑菇研究所）、长唄三味線
- **底色**：米白 `#F5F1E8`、淡彩晕染
- **文字**：竖排毛笔标题 + 手写小字；字体有温度
- **图形**：细腻手绘插画（动物、植物、刺绣质感、水彩晕染），线条生动
- **布局**：插画占主体，文字沿角落或留白处竖排；弱边框
- **配色**：水彩淡彩 + 米白 + 少量墨色
- **要点**：手绘质感是灵魂，画面有"呼吸感"

## 四、字体选择（本地可用字体）

**语言原则**：海报文字语言跟随用户原文，不把中文翻译成日文。日式指的是视觉风格，不是文字语言。脚本会用 `detect_language()` 从文案自动判断语言（含假名→日文，含汉字→中文），加载对应字体族；也可用 config 的 `language` 字段（zh/ja）强制指定。

**日文文案字体族（Hiragino）**：
- **明朝体（细，正文/竖排诗意）**：`ヒラギノ明朝 ProN.ttc` index 0（W3）
- **明朝体（粗，标题）**：`ヒラギノ明朝 ProN.ttc` index 2（W6）
- **哥特体/黑体（现代）**：`ヒラギノ角ゴシック W4.ttc` index 0
- **圆体（可爱/美食）**：`ヒラギノ丸ゴ ProN W4.ttc` index 1

**中文文案字体族（宋体/苹方）**：
- **宋体（细，正文/竖排诗意/标题常规）**：`Supplemental/Songti.ttc` index 3（Songti SC Light）
- **宋体（粗，标题）**：`Supplemental/Songti.ttc` index 1（Songti SC Bold）
- **苹方（黑体/现代）**：`PingFang.ttc` index 2（SC Regular）/ index 8（SC Semibold）

**西文**：衬线用 Songti SC（index 6，含拉丁字形），无衬线用 `HelveticaNeue.ttc`。

- `seigaiha()`：青海波（同心半圆）
- `asanoha()`：麻叶纹（六边形放射）
- `ichimatsu()`：市松格纹
- `ensou()`：圆相（手绘圆）
- `seal()`：朱印印章
- `fan()`：折扇
- `wave()`：波浪线
- `dot_grid()`：点阵
- `paper_texture()`：和纸肌理（噪点+纤维）
- `cloud_shape()`：云形轮廓
- `rain_lines()`：斜向雨丝
- `umbrella()`：手绘雨伞（伞骨+伞柄弯钩）

- `fried_chicken()`：金黄酥脆炸鸡块（含欧芹碎点、纸托）

E 版式 `scene` 字段：`botanical`（默认，花枝小鸟）/ `rain_pickup`（雨天接孩子：雨丝+雨伞+牵手身影+水洼），适合亲子、放学、温情生活场景。

C 版式 `dish` 字段：`wagashi`（默认，和菓子球）/ `fried_chicken`（炸鸡块），适合炸鸡、小吃、休闲美食主题；有真实照片时用 `image` 字段优先。

## 六、版式黄金比例

- 海报尺寸：推荐 3:4（如 900×1200）或 B5/A4 比例（798×1123）
- 安全边距：画面宽度的 8%–10%
- 标题区：画面高度 15%–35%
- 主体图形区：画面高度 40%–60%
- 信息区（日期/地点/落款）：底部 10%–15%
- 竖排文字：字距为字号的 1.3–1.6 倍，行距为字号 2–2.5 倍

## 七、避坑清单

1. 不要塞入过多元素，一页一个视觉焦点。
2. 不要使用高饱和渐变或 colorful shadow。
3. 不要中西文混排时字号相同——英文要明显小一号。
4. 不要把文字完全铺满，留白至少 30%。
5. 印章不要过大（画面宽度 5%–10% 即可）。
6. 字体不要超过 2 种（一种日/中文，一种西文）。
7. 生成后必须检查图片，确认无文字溢出、无元素重叠。
